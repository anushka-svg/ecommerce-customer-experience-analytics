# KPI Dictionary

This document defines the key performance indicators used
throughout the analysis.

Final formulas will be confirmed after data validation.

| KPI | Description |
|---|---|
| Total Orders | Total number of orders |
| Delivered Orders | Orders successfully delivered |
| Cancellation Rate | Percentage of orders cancelled |
| Average Delivery Time | Average time between purchase and delivery |
| Late Delivery Rate | Percentage of delivered orders arriving after estimated date |
| On-Time Delivery Rate | Percentage delivered on or before estimated date |
| Average Review Score | Average customer review rating |
| Low Rating Rate | Percentage of reviews with scores of 1 or 2 |
| Repeat Customer Rate | Percentage of customers with multiple purchases |
| Seller Late Delivery Rate | Percentage of seller orders delivered late |
| Seller Average Rating | Average review score associated with seller orders |
